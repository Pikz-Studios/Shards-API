# API Overview

The Shards API provides access to:

| Component            | Description                            |
| -------------------- | -------------------------------------- |
| `ShardsAPI`          | Main API entry point                   |
| `OfflineUserAPI`     | Player shard balance management        |
| `LeaderboardAPI`     | Leaderboard GUI access                 |
| `AFKManagerAPI`      | AFK teleportation system               |
| `ShopAPI`            | Shop management                        |
| `GenMultiplayerAPI`  | Generation bonus multipliers           |
| `KillMultiplayerAPI` | Kill bonus multipliers                 |
| `ShardGainEvent`     | Event fired when a player gains shards |
| `ShardLoseEvent`     | Event fired when a player loses shards |
